# CLAUDE.md

Personal Pokémon Emerald ROM hack built on the pret decompilation.

## Branches
- `postgame-tweaks`: all hack work happens here. Commit and push changes to it.
- `master`: untouched mirror of pret/pokeemerald (byte-matching build). Don't commit hack changes to it.
- `expansion`: stock rh-hideout/pokeemerald-expansion. Separate codebase with an incompatible save format; leave it alone unless asked.

## Building
- The SessionStart hook (`.claude/hooks/session-start.sh`) installs the toolchains only.
- **Only build when the user asks.** Use `make modern -j4`, which produces `test_PokemonEmerald_Modern.gba`.
- The matching build (`make`) no longer reproduces `rom.sha1` on this branch. That's expected.
- To compile a single file without building the ROM: `make MODERN=1 build/modern/src/<file>.o`.
- After a build, send `test_PokemonEmerald_Modern.gba` to the user with SendUserFile (`display: attach`). They test it on a phone emulator.

## Save compatibility
The user plays on existing saves. Avoid changes to the `SaveBlock1`, `SaveBlock2` or `PokemonStorage` layouts (`include/global.h`, `include/pokemon_storage_system.h`); they break existing saves. If a change requires it, say so first. SaveBlock1 has only about 120 bytes free.

## Changes so far
- **Post-game Master Balls:** after `FLAG_SYS_GAME_CLEAR`, any normal mart that sells a Poké Ball item also lists the Master Ball first (`AddPostGameMartItems` in `src/shop.c`). The Master Ball price is 50,000 (`src/data/items.h`).
- **Running Shoes from the start:** the `FLAG_SYS_B_DASH` check was removed from the run check in `src/field_player_avatar.c`, so running works on existing saves too. Mom's Running Shoes scene in Littleroot still plays; it's harmless. Running is allowed on every map now (see auto-run below).
- **Running in Poké Centers and Marts:** `allow_running` set to true in the `map.json` of every `*_PokemonCenter_1F/2F`, every `*_Mart` and `EverGrandeCity_PokemonLeague_1F`. (now redundant: every map allows running).
- **Auto-run everywhere:** the player runs by default and holds B to walk (`src/field_player_avatar.c`). `IsRunningDisallowed` (`src/bike.c`) ignores the map header's `allowRunning`; only `IsRunningDisallowedByMetatile` tiles (deep sand, etc.) still prevent running.
- **Instant text:** `RunTextPrinters` in `src/text.c` draws every character up to the next prompt, scroll or pause in one frame (capped at `MAX_TEXT_CHARS_PER_FRAME`), at every text speed (`AddTextPrinter` sets the per-character delay to 0), and copies the window to VRAM once per frame. Line scrolling also happens in one frame. The Text Speed row was removed from the Options menu (`src/option_menu.c`); `optionsTextSpeed` stays in the save but is unused.
- **Double-speed Birch intro:** while `sBirchSpeechDoubleSpeed` is set (`src/main_menu.c`), `CB2_MainMenu` runs tasks and sprite animations twice per frame, clearing new key presses before the second pass. Normal palette fades still run at normal speed.
- **Instant Nurse Joy healing:** `Common_EventScript_PkmnCenterNurse` in `data/scripts/pkmn_center_nurse.inc` goes straight to healing, skipping the yes/no question (and the Gold Card greeting, which is now unused).
- **Shiny Charm (new key item `ITEM_SHINY_CHARM`, after `ITEM_OLD_SEA_MAP`):** uses the Star Piece icon recolored gold (`graphics/items/icon_palettes/shiny_charm.pal`). Put in the PC once the first time the bedroom or Poké Center PC is opened (`GiveShinyCharmOnce` in `src/player_pc.c`, guarded by `FLAG_RECEIVED_SHINY_CHARM`, formerly `FLAG_UNUSED_0x020`). While it's in the **bag**, Pokémon generated for the player roll their personality up to `SHINY_CHARM_ROLLS` (3) times and keep the first shiny one (`GetShinyRolls`/`IsShinyForPlayer` in `src/pokemon.c`; used by `CreateBoxMon`, `CreateMonWithNature`, `CreateMonWithGenderNatureLetter` and daycare eggs in `src/daycare.c`). Odds go from 1/8192 to about 1/2731.
- **Badge shiny bonus:** each gym badge adds a 1-in-8 chance of one extra roll in `GetShinyRolls` (8 badges = always +1). Odds: 1/8192 with no badges, 1/4096 with all 8; with the charm, 1/2731 to 1/2048. The shiny threshold (`SHINY_ODDS`) is unchanged, so already-caught Pokémon never change appearance.
- **Legendary shiny bonus:** each of the 21 Gen 1–3 legendary/mythical Pokémon registered as caught in the Pokédex adds one roll (`sLegendaryDexNums` in `src/pokemon.c`). With the charm and 8 badges, all 12 obtainable in this game bring the odds to 1/512.
- **Champion shiny bonus:** `FLAG_SYS_GAME_CLEAR` adds `SHINY_CHAMPION_ROLLS` (4) rolls. Everything combined (charm, 8 badges, Champion, 12 legendaries) gives 20 rolls, about 1/410.
- **Event islands unlocked:** after `FLAG_SYS_GAME_CLEAR`, the first PC visit puts the Eon Ticket, Aurora Ticket, Old Sea Map and Mystic Ticket in the PC and sets the four `FLAG_ENABLE_SHIP_*` flags, like the Mystery Gift scripts did (`GiveEventTicketsOnce` in `src/player_pc.c`, guarded by `FLAG_RECEIVED_EVENT_TICKETS`, formerly `FLAG_UNUSED_0x021`). The Lilycove ferry needs the ticket in the bag. The island maps and scripts are vanilla.
- **New Game Plus:** after `FLAG_SYS_GAME_CLEAR`, the bed in the player's room (bg_event on the solid lower bed tile: x=1,y=5 in `LittlerootTown_BrendansHouse_2F`, x=7,y=5 in `LittlerootTown_MaysHouse_2F`) runs `PlayersHouse_2F_EventScript_Bed` (`data/scripts/new_game_plus.inc`). After two yes/no prompts it calls special `StartNewGamePlus`, which runs `CB2_NewGamePlus` → `NewGamePlusInitData` (`src/new_game.c`). That wraps `NewGameInitData` and keeps the name, gender, options and Trainer ID (restored after `InitPlayerTrainerId`), all money, all Master Balls (bag + PC, put in the bag), and every starter from earlier runs (Hoenn starter line, player's OT, met on Route 101 at Lv. 5; rebuilt as the first stage at Lv. 5 with default moves, keeping personality, IVs, ability, nickname and OT). They all go into PC box 1 (up to 30), so the party starts empty and the opening plays as normal. It stores `GetShinyRolls() / NGP_SHINY_ROLL_DIVISOR` (5) in `VAR_NGP_SHINY_ROLLS` (formerly `VAR_UNUSED_0x404E`), which `GetShinyRolls` adds; the charm counts even if it's in the PC. Nothing is written to flash until the player saves, and the game's "overwrite save?" prompt still appears.
- **Shiny rolls on the Trainer Card:** the back of the player's own Emerald card shows `SHINY ROLLS  <average rolls> (1/<odds>)` (`PrintShinyRollsOnCard` in `src/trainer_card.c`), in the first empty link-stat row (1–4, else row 6 below the panel). `GetShinyRolls` is split into `GetGuaranteedShinyRolls` + the badge chance; `GetAverageShinyRollsTimesBadges` and `GetShinyOddsDenominator` (exact, 32-bit fixed point) feed the card.
- **Instant battle bars:** `MoveBattleBar` (`src/battle_interface.c`) runs every `CalcNewBarValue` step in one call, so HP and EXP bars (and the HP number) jump to the new value in one frame and report done on the next call. `EXP_BAR_DELAY_FRAMES` (`include/battle_interface.h`, vanilla 13) is 0, used by the player and partner controllers' `Task_GiveExpWithExpBar`.
- **No nickname prompt after catching:** `BattleScript_TryNicknameCaughtMon` (`data/battle_scripts_2.s`) no longer prints the question, and `Cmd_trygivecaughtmonnick` (`src/battle_script_commands.c`) starts at state 4, the vanilla "NO" path (party, or PC with the usual message if full). Gift Pokémon from event scripts still ask.
- **VS Seeker:** the existing `ITEM_VS_SEEKER` now uses `ItemUseOutOfBattle_VsSeeker` (`src/item_use.c`), which runs `EventScript_UseVsSeeker` (`data/scripts/vs_seeker.inc`) → special `UseVsSeeker` (`src/battle_setup.c`). For each beaten trainer object within 7×5 tiles: rematch-table trainers up to `REMATCH_SPECIAL_TRAINER_START` (not gym leaders/E4) get `SetRematchIdForTrainer` (next team; talk to them), and other trainers whose script is plain `TRAINER_BATTLE_SINGLE`/`DOUBLE` (no post-battle script) get their trainer flag cleared so they challenge again. Each shows an exclamation emote. Recharge: `VAR_VS_SEEKER_STEPS` (formerly `VAR_UNUSED_0x4083`) is set to `VS_SEEKER_RECHARGE_STEPS` (100) on success and counts down per step (`UpdateVsSeekerStepCounter`, called from `field_control_avatar.c`). Not usable in the Battle Pyramid or Trainer Hill. Roxanne gives it after the TM (`RustboroCity_Gym_EventScript_GiveVsSeeker`, `FLAG_RECEIVED_VS_SEEKER`, formerly `FLAG_UNUSED_0x022`); talking to her again gives it on older saves. Match Call rematches still work.
- **EXP. SHARE key item (`ITEM_EXP_SHARE_KEY`, after `ITEM_SHINY_CHARM`, Exp. Share icon):** using it from the bag or Select toggles `FLAG_EXP_SHARE_ON` (formerly `FLAG_UNUSED_0x023`; `ItemUseOutOfBattle_ExpShareKey` in `src/item_use.c`). While on and in the bag, `Cmd_getexp` (`src/battle_script_commands.c`) gives participants their normal split and every other party member half the base EXP (`calculatedExp / 2`), skipping eggs, fainted Pokémon and the in-game partner's Pokémon; the held EXP. SHARE's effect is ignored then. Mr. Stone gives it instead of the held item (`FLAG_RECEIVED_EXP_SHARE_KEY`, formerly `FLAG_UNUSED_0x024`); on older saves, talking to him again gives it. The held `ITEM_EXP_SHARE` is unchanged.
- **Poké Center 2F services (all 16 `*_PokemonCenter_2F` maps):** the left counter (was the Wireless Club attendant) is a Day Care man (`OBJ_EVENT_GFX_OLD_MAN`) running `PokemonCenter_2F_EventScript_DaycareCounter` (`data/scripts/pokemon_center_2f.inc`): remote access to the Route 117 Day Care, reusing its scripts. It sets `VAR_TEMP_F` to `DAYCARE_COUNTER_REMOTE` (`include/constants/daycare.h`) so `Route117_PokemonDayCare_EventScript_RetrieveMon` skips the lady's walk. The middle counter (was Union Room) is the gift terminal, `PokemonCenter_2F_EventScript_GiftTerminal`. The right counter (was the Direct Corner link attendant, so cable link play is gone) is the black market grunt. The first-visit tour (`CableClub_EventScript_Tutorial`, triggered by `VAR_CABLE_CLUB_TUTORIAL_STATE` 1 from Birch's lab) now uses `PokemonCenter_2F_Text_TourIntro`/`TourCounters`, where TEALA (the gift terminal NPC) explains the three counters.
- **Gift Pokémon terminal (`src/gift_mon_terminal.c`):** specials `CountUnlockedGiftMons`, `ShowGiftMonTerminalMenu` (list menu with prices), `BufferGiftMonInfo` and `TryBuyGiftMon` (results in `include/constants/gift_mon_terminal.h`). `sGiftMons` lists species, level, unlock (badge count, or `UNLOCK_CHAMPION`) and price: Kanto starters (1 badge), Johto starters (2), Eevee/Togepi (3), Lapras/Porygon (4), Jirachi (5), Celebi (6), Mew (7), Deoxys (8), and 17 legendaries after `FLAG_SYS_GAME_CLEAR`. `sGiftItems` adds the five fossils at 1 badge (Root/Claw/Helix/Dome ¥7,000, Old Amber ¥10,000); their menu ids start at `GIFT_ITEM_ID_START` (100), `BufferGiftMonInfo` sets VAR_RESULT TRUE for items (separate confirm text), and `TryBuyGiftMon` returns `GIFT_ITEM_BOUGHT`/`GIFT_ITEM_BAG_FULL`. Repeatable purchases; no save data. Bought Pokémon get shiny rolls, `MON_DATA_MODERN_FATEFUL_ENCOUNTER` (so Mew/Deoxys obey) and Pokédex caught flags (so legendaries count for the legendary shiny bonus). If the party is full they go to the PC; if that's full too, nothing is charged.
- **Black market grunt (right counter of every `*_PokemonCenter_2F`):** `OBJ_EVENT_GFX_MAGMA_MEMBER_M/F` running `PokemonCenter_2F_EventScript_MagmaGrunt` in Oldale, Petalburg, Rustboro, Verdanturf, Mauville, Fallarbor, Lavaridge and Fortree; `OBJ_EVENT_GFX_AQUA_MEMBER_M/F` running `PokemonCenter_2F_EventScript_AquaGrunt` in Dewford, Slateport, Lilycove, Mossdeep, Sootopolis, Pacifidlog, Ever Grande and the Battle Frontier (`data/scripts/pokemon_center_2f.inc`, BUY/SELL/QUIT via `MULTI_BUY_SELL_QUIT`). Code in `src/black_market.c` (sell results in `include/constants/black_market.h`). **Buy:** `GetTodaysStock` picks `STOCK_SIZE` (5) different Pokémon from `sBlackMarketPool` (42 species Emerald can't catch, plus a few rare Hoenn ones) with a generator seeded by the RTC day count (`gLocalTime.days`), so the stock is the same in every center and changes daily; no save data. Level is 5 + 5 per badge (Lv. 50 after `FLAG_SYS_GAME_CLEAR`); price is the base price + 200 per level. Purchases go through `BuyMonForPlayer` (shared with the gift terminal in `src/gift_mon_terminal.c`, which also exports the list menu `ShowShopListMenu` taking `struct ShopListEntry` name/id/price, price 0 = none; `include/gift_mon_terminal.h`), so they get shiny rolls and Pokédex flags. **Sell:** party Pokémon only, via `ChoosePartyMon`; price = (100 × level + 50 × total IVs) × 10 if shiny. Eggs, the last Pokémon that can battle, and Pokémon holding Mail can't be sold; a held item goes back to the bag (refused if the bag is full).
- **Altering Cave mixed table:** `GetCurrentMapWildMonHeaderId` (`src/wild_encounter.c`) and the Pokédex area screen ignore `VAR_ALTERING_CAVE_WILD_SET` and always use `gAlteringCave1`, whose 12 land slots now hold all nine species (`src/data/wild_encounters.json`): Zubat 24%, Mareep 20%, Pineco/Teddiursa/Aipom 10% each, Houndour 11%, Stantler 6%, Shuckle 5%, Smeargle 4%. Tables 2–9 are unused.
- **Kanto fossil revival:** `src/fossil_revival.c` (`sFossils`: Root→Lileep, Claw→Anorith, Helix→Omanyte, Dome→Kabuto, Old Amber→Aerodactyl). `VAR_WHICH_FOSSIL_REVIVED` = 1 + index (1/2 are the vanilla Root/Claw values, so revivals in progress on old saves still work). The Devon Corp. 2F scientist (`RustboroCity_DevonCorp_2F_EventScript_FossilScientist`) uses specials `CountFossilsInBag`, `GetFirstFossilInBag`, `ShowFossilChoiceMenu` (list menu when the bag holds more than one kind), `HandFossilToResearcher` and `GetRevivedFossilSpecies`, with one generic receive flow (species in `VAR_0x8005`, Lv. 20). `MULTI_FOSSIL` is now unused.
- **Mirage Island more often:** `IsMirageIslandPresent` (`src/time_events.c`) also returns TRUE when the daily Mirage number (`VAR_MIRAGE_RND_H`, re-rolled by `UpdateMirageRnd` each new RTC day) is divisible by `MIRAGE_ISLAND_DAILY_CHANCE` (4), so the island shows on about 1 day in 4; the vanilla party-personality match still works. The Route 130 map script and the Pacifidlog watcher use the same special.
- **IV/EV view on the summary screen:** pressing A on the Skills page cycles the stat columns through Stats → IVs → EVs (`CycleSkillsStatsMode` in `src/pokemon_summary_screen.c`, mode in `skillsStatsMode`, formerly `filler40CA`). The title changes to POKéMON IVs/EVs. In EV mode the EXP rows show EV TOTAL and EVs LEFT (of `MAX_TOTAL_EVS`, 510). The mode stays while switching Pokémon or pages and resets when the screen closes. Display only; no save data.
- **pret bug fixes applied:** every `#ifdef BUGFIX`/`#ifndef BUGFIX` block in `src/` and `data/` was resolved to its fixed branch and the directives removed, so the fixes are always on without defining `BUGFIX` (which now does nothing; `UBFIX` is still on via `MODERN`). Exception: `Cmd_forcerandomswitch` (`src/battle_script_commands.c`) keeps vanilla `lastMonId` (`PARTY_SIZE`, `PARTY_SIZE / 2`), because its loop uses `i < lastMonId` and pret's `- 1` would skip the last party slot. The old `// BUG:` comments above the fixed code were left in place.
